# Charles Wolfe — Professional Driver

Static, responsive one-page website. No build step required.

## Publish with GitHub Pages
1. Create a new public repository named `charles-wolfe-driver`.
2. Upload `index.html` (and optionally this README) to the repository root.
3. Go to **Settings → Pages → Build and deployment**.
4. Choose **Deploy from a branch**, select **main** and **/(root)**, then save.
5. Your site will be at `https://YOUR-USERNAME.github.io/charles-wolfe-driver/` after deployment.

## Google reviews
When Charles creates and verifies his Google Business Profile, replace the `Google Reviews — Coming Soon` element in `index.html` with an anchor pointing to his actual Google review link. Do not create a review link until it exists.
